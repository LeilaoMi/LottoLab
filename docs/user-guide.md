# 使用指南

[首页](../README.md) / 使用指南

建议按“准备数据 → 检查质量 → 观察统计 → 运行实验 → 保存结果”的顺序使用。SSQ 与 DLT 使用独立的号码规则，真实数据与演示数据分别选择。

## 访问与权限

| 环境 | 查询 | 同步、导入与计算 |
| :--- | :--- | :--- |
| 默认本地启动器 | 可直接使用 | 仅允许本机访问时可直接使用 |
| 默认 Docker Compose | 可直接使用 | 需本机访问或自配的 `LOTTOLAB_ADMIN_TOKEN` |
| Vercel 云端（未设令牌） | 公开可访问 | 公开可访问（无需登录） |
| Vercel 云端（已设令牌） | 公开可访问（含推荐/验奖GET） | 需管理员令牌（同步/导入/回测等POST） |

未设令牌的 Vercel 云端部署为公开模式：浏览数据与使用工作台都不需要任何令牌，也不再弹出“管理权限”输入框。设置至少 32 字符的 `LOTTOLAB_ADMIN_TOKEN` 后切为公开读、私有写：查询、推荐与验奖（GET）仍公开，同步、导入与计算（POST）需令牌。站点防护交由部署平台与 Cloudflare（域名校验、来源与请求大小限制、任务并发上限，建议再配单 IP 限流）承担。

本地与 Docker 部署仍保留更严格的写入策略：读取公开，但同步、导入、回测等写操作默认只允许本机（回环地址）访问，或自行设置 `LOTTOLAB_ADMIN_TOKEN` 后经界面盾牌图标输入。当前系统没有注册、独立用户账户或角色管理。

源码中没有预置任何公共账号或线上地址；自行部署即可获得独立的数据与实验空间。

## 同步与管理数据

顶部选择彩种和数据类型，点击“同步数据”获取历史开奖。系统优先尝试官方公开来源，失败时尝试备用来源；导入报告记录实际来源和失败信息。除手动同步外，仓库还配有每日定时作业自动追加当日最新开奖入库（幂等，只增不改）。

在“开奖数据”中可以按期号、日期筛选，浏览分页结果，导入或导出 CSV，并检查导入记录与质量问题。

- 同一期重复导入不会产生重复记录。
- 非法号码、日期问题和多来源冲突会记录原因。
- 对冲突确认修订后，保留原值与新值；已冻结的实验数据不被改写。
- 页面显示的是实际收录范围，不代表完整历史覆盖。缺失开奖不会自动补造。

## CSV 格式

必需四列，号码使用空格分隔。下面是一行 SSQ 格式示例：

```csv
issue,draw_date,main_numbers,special_numbers
2026105,2026-09-10,02 04 13 14 15 30,08
```

| 列 | 说明 |
| :--- | :--- |
| `issue` | 真实期号采用四位年份加三位序号 |
| `draw_date` | 开奖日期，格式为 `YYYY-MM-DD` |
| `main_numbers` | SSQ 为 1–33 中的 6 个号码；DLT 为 1–35 中的 5 个号码 |
| `special_numbers` | SSQ 为 1–16 中的 1 个号码；DLT 为 1–12 中的 2 个号码 |

可选列为 `lottery`、`dataset_kind`、`sales`、`pool_amount`、`prizes`。`lottery` 使用 `ssq` 或 `dlt`；`dataset_kind` 使用 `real` 或 `synthetic`，须与所选导入模式一致。

`prizes` 是以奖级为键、每注税前奖金为值的 JSON 对象。金额字段缺失时留空，不能以假定奖金补齐；JSON 中有逗号或引号时按 CSV 规则转义。

支持 UTF-8 和 GB18030 编码，每次最多 10,000 行。文件大小上限为本地 8 MiB、Vercel 4 MiB。导出后重新导入仍会执行相同校验。

## 观察与统计

“开奖观察”展示最新收录开奖、数据范围、号码频率与和值走势。“统计检验”提供遗漏、形态、分区、共现和随机性检验。

读取结果时同时检查彩种、窗口与样本量。频率较高只描述这个历史窗口；没有证据表明遗漏更久的号码下一期更容易出现。检验的 p 值、校正方法与假设应一起阅读，解释见 [研究方法](methodology.md)。

## 在线工具

「在线工具」面向全部 8 个彩种，把日常最常用的一站式操作放在一起：

- **号码推荐**：池型给 7 个策略（稳健·热号 / 进取·遗漏 / 冷热均衡 / 区间覆盖 / 冷热加权 / 随机基准 / 冷门避撞），数字型给 5 个（每位热/冷/均衡/随机/避撞）。每注带**结构分**（和值/奇偶/大小/三区/跨度/AC）、**撞号指数**（0–100，越低越少与人撞号，双色球/大乐透/七乐彩/快乐8 用真实一等奖注数回归、数字型用逐位注数），以及双色球的**冷门度**（预计同奖人数 = 8.27 × Π因子 + 因子分解）。用 seed 可复现，蓝球按策略不同。可一键**导出票面 CSV**。
- **注数与金额**：单式 / 复式 / 胆拖的注数与金额估算（含追号倍数）。
- **批量验奖**：粘贴多注票面 + 期号，逐期给出命中注数、奖级与金额（浮动/未定金额如实标注，不编造）。
- **策略回测**：滚动检验各推荐策略的实际平均命中，与均匀期望对照——用来诚实回答"这些策略准不准"。
- **预测复盘闭环**：把当前推荐登记到台账（填目标期号），该期开奖后自动对账命中率/奖级，累积成可核验的实盘记录。

关于研究页的彩种覆盖：**统计检验**（频率/遗漏/随机性）对全部 8 个彩种开放（数字型走逐位均匀性卡方）；**模型档案 / 滚动回测 / 随机模拟**面向池型（双色球/大乐透/七乐彩/快乐8）；**组合覆盖**面向双色球/大乐透/七乐彩（快乐8 20/80 覆盖不实际）。

推荐、冷门度与覆盖都只描述历史与分奖人数，**不改变任何一注的中奖概率**，期望回报仍为负。

## 模型与时间回测

“模型档案”介绍四种实现：均匀随机、历史频率、逻辑回归、梯度提升树。在“滚动回测”设置测试期数、训练窗口、随机种子与重新训练间隔后提交。每个模型每期生成一注，使用相同预算。

系统按时间顺序向前回放，预测一期时使用该期之前的数据，并在相同窗口、预算和规则下比较模型。结果包括指标、相对随机基线的差值、区间、前后半稳定性对照与逐期记录；JSON 导出后可用 `python scripts/export_report.py 报告.json` 生成 Markdown 摘要（打印到控制台，自行重定向保存到 `.local/`，不要提交进仓库）。

运行前应固定主要指标。反复尝试参数后只选择最佳结果，会扩大偶然发现的机会；当前系统保留实验历史，但不自动校正所有历史搜索。

## 随机模拟与组合覆盖

“随机模拟”用合法的无放回开奖生成 Monte Carlo 样本，并与理论分布对照。相同设置与随机种子支持重复实验，有限样本仍有抽样误差。

“组合覆盖”在预算和候选集合内生成合法、去重组合。结果分别展示候选池内的条件覆盖和完整主区空间中的估计覆盖；两者分母不同。贪心结果不保证全局最优，也不能解释为中奖保证。

SSQ 与 DLT 的历史收益只在相应奖级奖金完整且可追溯时才计算，使用税前口径、基本投注（不含追加与派奖）；DLT 按开奖日期选择奖级版本（2019-02-20 第19019期为界），固定奖缺数时按版本常量回退，浮动奖缺数则该期不计入。合成数据不提供历史 ROI。

## 任务状态与实验历史

本地 worker 顺序执行任务，队列与运行中的任务合计默认最多 8 项，单项默认限时 600 秒。Vercel 同时最多 1 项，单项最多 240 秒；云端提交请求会等待计算结束。

计算中可以查看状态并取消任务。云端页面提示等待时，请等待响应；连接断开后重新打开相应实验历史检查结果。请求或平台中断不能保证任务完成，失败后可降低规模重试。

数据和已提交的实验结果存储在数据库中。刷新页面后重新鉴权即可查看历史；同一实验冻结的数据不会随以后同步而变化。

## 常见问题

| 问题 | 说明 |
| :--- | :--- |
| 页面为空 | 云端公开无需鉴权；检查是否选对彩种与真实 / 演示类型、是否已同步或导入数据（私有自托管另需确认已输入令牌） |
| 最新期号落后 | 点击同步并查看导入报告；实际来源可能延迟或不可用 |
| 暂时不能新建实验 | 检查当前运行任务与队列容量 |
| 提示请求过于频繁 | 写操作与重算类查询按 IP 限流（写默认 120 次/分、推荐/验奖/覆盖默认 60 次/分），稍后重试；自托管可在配置中调整或关闭 |
| 计算超时 | 减少测试期数、训练窗口、模拟次数或覆盖规模后重试 |
| 云端首次响应较慢 | 函数和数据库可能需要从空闲状态唤醒 |
| 导入后旧实验没有变化 | 实验使用冻结数据；要比较新数据，请创建新实验 |
