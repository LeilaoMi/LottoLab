# 使用指南

[首页](../README.md) / 使用指南

建议按“准备数据 → 检查质量 → 观察统计 → 运行实验 → 保存结果”的顺序使用。SSQ 与 DLT 使用独立的号码规则，真实数据与演示数据分别选择。

## 访问与权限

| 环境 | 查询 | 同步、导入与计算 |
| :--- | :--- | :--- |
| 默认本地启动器 | 可直接使用 | 仅允许本机访问时可直接使用 |
| 默认 Docker Compose | 可直接使用 | 需要管理员令牌 |
| Vercel 云端 | 业务数据需要管理员令牌 | 需要管理员令牌 |

通过界面盾牌图标打开“管理权限”，输入自己部署配置中的 `LOTTOLAB_ADMIN_TOKEN`。令牌仅保存在当前页面内存中，刷新或重新打开后需要再次输入。当前系统没有注册、独立用户账户或角色管理。

现有 [线上实例](https://lottolab-zeta.vercel.app)需由部署者提供访问令牌。源码中没有预置公共账号；自部署者使用自己生成的配置。

## 同步与管理数据

顶部选择彩种和数据类型，点击“同步数据”获取历史开奖。系统优先尝试官方公开来源，失败时尝试备用来源；导入报告记录实际来源和失败信息。同步需要手动触发，未设置定时采集。

在“开奖数据”中可以按期号、日期筛选，浏览分页结果，导入或导出 CSV，并检查导入记录与质量问题。

- 同一期重复导入不会产生重复记录。
- 非法号码、日期问题和多来源冲突会记录原因。
- 对冲突确认修订后，保留原值与新值；已冻结的实验数据不被改写。
- 页面显示的是实际收录范围，不代表完整历史覆盖。缺失开奖不会自动补造。

## CSV 格式

必需四列，号码使用空格分隔。下面是一行 SSQ 格式示例：

```csv
issue,draw_date,main_numbers,special_numbers
2026105,2026-09-10,02 04 13 14 15 30,08
```

| 列 | 说明 |
| :--- | :--- |
| `issue` | 真实期号采用四位年份加三位序号 |
| `draw_date` | 开奖日期，格式为 `YYYY-MM-DD` |
| `main_numbers` | SSQ 为 1–33 中的 6 个号码；DLT 为 1–35 中的 5 个号码 |
| `special_numbers` | SSQ 为 1–16 中的 1 个号码；DLT 为 1–12 中的 2 个号码 |

可选列为 `lottery`、`dataset_kind`、`sales`、`pool_amount`、`prizes`。`lottery` 使用 `ssq` 或 `dlt`；`dataset_kind` 使用 `real` 或 `synthetic`，须与所选导入模式一致。

`prizes` 是以奖级为键、每注税前奖金为值的 JSON 对象。金额字段缺失时留空，不能以假定奖金补齐；JSON 中有逗号或引号时按 CSV 规则转义。

支持 UTF-8 和 GB18030 编码，每次最多 10,000 行。文件大小上限为本地 8 MiB、Vercel 4 MiB。导出后重新导入仍会执行相同校验。

## 观察与统计

“开奖观察”展示最新收录开奖、数据范围、号码频率与和值走势。“统计检验”提供遗漏、形态、分区、共现和随机性检验。

读取结果时同时检查彩种、窗口与样本量。频率较高只描述这个历史窗口；没有证据表明遗漏更久的号码下一期更容易出现。检验的 p 值、校正方法与假设应一起阅读，解释见 [研究方法](methodology.md)。

## 模型与时间回测

“模型档案”介绍四种实现：均匀随机、历史频率、逻辑回归、梯度提升树。在“滚动回测”设置测试期数、训练窗口、随机种子与重新训练间隔后提交。每个模型每期生成一注，使用相同预算。

系统按时间顺序向前回放，预测一期时使用该期之前的数据，并在相同窗口、预算和规则下比较模型。结果包括指标、相对随机基线的差值、区间与逐期记录；JSON 导出用于进一步复核。

运行前应固定主要指标。反复尝试参数后只选择最佳结果，会扩大偶然发现的机会；当前系统保留实验历史，但不自动校正所有历史搜索。

## 随机模拟与组合覆盖

“随机模拟”用合法的无放回开奖生成 Monte Carlo 样本，并与理论分布对照。相同设置与随机种子支持重复实验，有限样本仍有抽样误差。

“组合覆盖”在预算和候选集合内生成合法、去重组合。结果分别展示候选池内的条件覆盖和完整主区空间中的估计覆盖；两者分母不同。贪心结果不保证全局最优，也不能解释为中奖保证。

SSQ 历史收益只有在相应奖级奖金完整且可追溯时才计算，使用税前口径；合成数据和 DLT 当前不提供历史 ROI。

## 任务状态与实验历史

本地 worker 顺序执行任务，队列与运行中的任务合计默认最多 8 项，单项默认限时 600 秒。Vercel 同时最多 1 项，单项最多 240 秒；云端提交请求会等待计算结束。

计算中可以查看状态并取消任务。云端页面提示等待时，请等待响应；连接断开后重新打开相应实验历史检查结果。请求或平台中断不能保证任务完成，失败后可降低规模重试。

数据和已提交的实验结果存储在数据库中。刷新页面后重新鉴权即可查看历史；同一实验冻结的数据不会随以后同步而变化。

## 常见问题

| 问题 | 说明 |
| :--- | :--- |
| 页面为空 | 检查是否已鉴权、选对彩种和真实 / 演示类型，以及是否已导入数据 |
| 最新期号落后 | 点击同步并查看导入报告；实际来源可能延迟或不可用 |
| 暂时不能新建实验 | 检查当前运行任务与队列容量 |
| 计算超时 | 减少测试期数、训练窗口、模拟次数或覆盖规模后重试 |
| 云端首次响应较慢 | 函数和数据库可能需要从空闲状态唤醒 |
| 导入后旧实验没有变化 | 实验使用冻结数据；要比较新数据，请创建新实验 |
