# 研究方法与边界

[首页](../README.md) / 研究方法

LottoLab 用历史数据检验假设，保留实验设置与结果，便于复核。当前实现不预设模型应优于随机基线，也不把“未发现显著差异”解释为已经证明绝对随机。

## 号码规则与零模型

默认零模型假设各期独立、合法组合等概率。每个区内无放回抽样，不能把同一期的多个号码视为独立抽取。

| 彩种 | 主区 | 附加区 | 完整单注组合数 |
| :--- | :--- | :--- | ---: |
| 双色球 SSQ | 33 选 6 | 16 选 1 | 17,721,088 |
| 大乐透 DLT | 35 选 5 | 12 选 2 | 21,425,712 |

组合总数为 `C(主区总数, 主区选取数) × C(附加区总数, 附加区选取数)`。在这一零模型下，每种合法完整组合的概率相同。

例如固定选择 6 个 SSQ 红球时，红球命中数服从超几何分布 `Hypergeometric(33, 6, 6)`，期望为 `36/33`。和值、奇偶数和分区计数也使用相应的无放回分布。

## 数据来源与可复现性

数据导入保存来源、导入时间与原始内容的 SHA-256。原始快照在本地保存为文件，在云端压缩入库；异常和冲突保留记录，修订不会静默覆盖来源证据。

实验保存参数、随机种子、规则和特征版本、冻结数据、逐期结果及执行代码指纹。后续导入不会改变已冻结的数据。同样的数据、版本、参数和依赖环境是复现实验的前提。

仓库不附带历史数据库。实例中的最早 / 最晚日期表示实际收录范围，不能单凭范围证明中间没有缺期，也不代表官方完整历史。真实与 synthetic 数据分开，模拟记录以 `SIM-` 开头。

当前没有完整的历史“数据首次发布时间”档案或独立解析器版本表；回测按已收录的历史开奖时间排列，不宣称完整重建每个历史时点的数据可见性。

## 描述统计与随机性检验

描述统计包括号码频率、遗漏、和值、跨度、奇偶、大小号、连号、重号、分区与共现。窗口和样本量随结果展示；观察到的模式首先是对该窗口的描述。

整体频率、离散分布、游程与序列相关等检验按适用的无放回零模型计算或模拟。Monte Carlo p 值使用 `(b + 1) / (B + 1)`：`B` 为零模型重复次数，`b` 为模拟统计量至少同样极端的次数。零次超越也不表示真实 p 值为零。

同一组随机性检验报告 Bonferroni 校正结果。逐号码区间、经验分布距离和相关强度帮助解释偏离大小；显著 p 值本身不能证明偏离有实际价值或可用于预测。

## 概率输出

以下含义必须区分：

| 输出 | 含义 |
| :--- | :--- |
| 号码入选边际概率 | 某个号码出现在下一期开奖该区中的概率 |
| 排序分数 | 用于号码排序，不自动等于概率 |
| 抽样权重 | 控制生成组合时的选择权重 |
| 完整组合联合概率 | 某一整注组合发生的概率 |

SSQ 主区边际概率共有 33 个，和为 6；附加区和为 1。DLT 对应为 5 与 2。模型通过基数投影满足合法边际概率约束；**投影不等于经验概率校准**，边际概率也不能随意相乘得到完整组合概率。

## 特征与时间回测

特征由当期之前的历史生成，包括短中长窗口频率、累计频率、遗漏和近期入选状态。生成第 `t` 期特征后才读取该期开奖，避免当期信息进入输入。

| 模型 | 当前用途 |
| :--- | :--- |
| Uniform | 均匀概率与随机组合基线 |
| Historical Frequency | 近期历史频率基线 |
| Logistic Regression | 带训练侧标准化的逻辑回归 |
| Gradient Boosting | 基于历史因果特征的梯度提升树 |

回测按期向前移动，使用受上限约束的训练窗口，按配置间隔重新训练。同一期号码级样本不会分散到训练与测试两侧；标准化等拟合步骤只使用训练数据。

当前采用固定模型超参数，不提供自动调参或独立概率校准器。训练窗口限制拟合所用样本；每个样本的累计历史特征仍可包含该样本之前更早的历史。

## 评价与模型比较

主要比较指标是**主区逐号码平均二元 Brier 分数**，越低越好。模型优势定义为：

```text
优势 = 均匀随机基线 Brier − 模型 Brier
```

正值表示该测试窗口中模型的 Brier 更低。辅助结果包括二元 Log Loss、主区与附加区命中数、Precision / Recall、命中事件比例和校准分箱。

比较使用相同期开奖上的成对差值，以循环移动块 bootstrap 估计差值区间和中心化零假设下的双侧 p 值。本次运行的模型比较使用 Bonferroni 校正。

95% 区间是名义区间，块 bootstrap 依赖局部平稳近似。重叠窗口、反复调参和事后选择最佳结果都会影响解释；当前校正范围是**单次实验内的比较**，不覆盖所有历史搜索，也没有不可重复访问的确认性检验集。

## Monte Carlo 与组合覆盖

Monte Carlo 按合法的无放回开奖机制模拟，命中分布与精确理论分布对照，并报告抽样误差或区间。稀有事件在有限次模拟中未出现，不能据此认定其概率为零。

覆盖优化使用贪心方法，在给定预算、候选集合和目标命中阈值下生成合法去重组合。候选空间较小时可精确核对，较大空间采用估计并给出区间。

- **候选池内条件覆盖**：以所选候选池中的组合为分母，只在这个条件范围内解释。
- **完整主区空间覆盖**：以所有合法主区开奖为分母，与条件覆盖分别报告。

这些覆盖指标描述指定命中目标，不等于完整头奖概率；贪心方法不声称全局最优，也不提供无条件保底。

## 成本与收益

历史 ROI 按 `(总派奖 − 总成本) / 总成本` 计算。当前 SSQ 使用对应期可追溯的历史每注奖金，按基础单注 2 元、税前口径结算；不重算新增投注对浮动奖分配的影响。

缺少必要奖级信息或使用 synthetic 数据时，不输出历史 ROI。DLT 的历史奖级生效区间尚未完整建模，当前禁用其 ROI。情景或模拟收益不充当真实实现收益。
